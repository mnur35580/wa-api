Dokumentasi API

Endpoint API Server Anda

Gunakan endpoint ini di aplikasi Gudang Management Anda atau Klien Anda.

  • Kirim Teks: POST http://[IP_VPS_ATAU_DOMAIN_ANDA]:3000/api/send
  • Kirim Media: POST http://[IP_VPS_ATAU_DOMAIN_ANDA]:3000/api/send-media
Autentikasi (WAJIB)

Semua request wajib menyertakan API Key dari menu Devices pada Header HTTP:

Headers: {
  "x-api-key": "COPY_API_KEY_DARI_HALAMAN_DEVICES",
  "Content-Type": "application/json"
}
Contoh Request JSON (Kirim Teks)
{
  "number": "08123456789",
  "message": "Halo, barang SPK-001 sudah dikirim dari gudang!"
}
Catatan Penting
Jika menggunakan /api/send-media (Kirim Dokumen/Gambar), pastikan Anda menggunakan tipe form multipart/form-data saat memanggil API (jangan gunakan JSON). Format parameternya: number, type (image/document/video), dan file (file binernya).
